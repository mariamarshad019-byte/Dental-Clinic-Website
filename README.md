# 🦷 Dental Clinic Website

A modern, responsive dental clinic website designed to provide information about dental services and help visitors connect with a dental clinic.

## 🌐 Live Website

[Visit Dental Clinic Website](https://mariamarshad019-byte.github.io/Dental-Clinic-Website/)

## ✨ Features

- Responsive navigation bar
- Attractive hero section
- Dental services section
- About Us section
- Why Choose Us section
- Patient testimonials
- Free consultation form
- Newsletter section
- Responsive footer
- Hover effects and interactive styling

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- JavaScript

## 🚀 Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

```bash
npm install
```

4. Start Tailwind CSS:

```bash
npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
```

5. Open `index.html` in your browser.
